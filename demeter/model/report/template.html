Can a rules-based dual-engine model match Demeter?

Six candidate models built on 141 years of index data, each tuned only on data ending June 2012 and then run untouched across Demeter's live record. This is what the honest out-of-sample answer looks like — including one model that would have looked like a triumph if the test had started in 2012.

The verdict

How the test was run

Method

The discipline matters more than the models. Everything below was fixed before the out-of-sample window was looked at.

Rules of the exercise

1

Signal definition

A model is a function of daily market data returning a target leverage between 0 and 3 for the next session. Leverage 0 is the cash engine, earning the 3-month T-bill.

2

Causality enforced by test

Every model is re-run on truncated histories at five cut-off dates; if any signal value changes, the model is rejected. All six candidates pass.

3

Development window only

Parameters were chosen on data ending 30 June 2012 and checked for a plateau on the longer 1950–2012 sample. Out-of-sample results were computed once per model, after freezing.

4

Costs charged

2 bp of notional per unit of leverage traded, plus a financing-spread sensitivity of up to 50 bp a year on borrowed exposure. Cash earns the actual T-bill rate — Demeter books cash at 0%.

Data and its limits

Return accounting

For target leverage L on day t, the next day's portfolio return is

r[t+1] = rf[t+1] + L·(total_return[t+1] − rf[t+1]) − max(L−1, 0)·financing_spread/252 − |L − L_prev|·cost_bps/10,000

This is a futures-like accounting: the levered leg pays financing above the risk-free rate, the cash leg earns it.

What the record implies

Demeter's fingerprint

Before building anything, the published monthly returns were inverted against daily market data to ask what the underlying daily rule must have been doing. Implied exposure is the month's strategy return divided by SPY's, for months where SPY moved more than 2%.

Ingredients the record supports

    What the record rules out

      Monthly implied exposure

      Each bar is one month's implied exposure to SPY. Three months are exactly 0.00% — full cash. Note the negative bars: months where the strategy and the market moved in opposite directions, which no fixed exposure can produce.

      The central finding

      The rule that looks brilliant — until you test it earlier

      The single best-fitting archetype for Demeter's record is "hold 3× while VIX is below its 10-day average, otherwise cash". Across Demeter's live window it compounds at 18.3% a year. Across 1990–2012 it loses money and draws down 92%.

      Same rule, two eras

      Buying when implied volatility has just fallen is buying after up days. In a fourteen-year bull market that is a momentum tailwind; through 2000–02 and 2008 it is a whipsaw machine. A study that started its backtest in 2012 would have shipped this model.

      Does it survive contact with reality

      Sensitivity

      Trading costs, financing spreads, parameter perturbations, a longer out-of-sample window and a different instrument.

      Costs and financing

      Annualised return at each trading cost and financing spread. A low-turnover model is barely affected by costs; the financing spread on levered exposure matters more.

      What breaks it

      The model's weak spots, from the perturbation grid and the variant runs below.

        Parameter perturbations

        Each of the six parameters moved ±15% and ±30% from its frozen value, re-run out of sample. A plateau — not a spike at the chosen value — is what robustness looks like.

        Different windows and instruments

        The 2005-start window includes the 2008 crisis, which is outside both the development sample's end and the Demeter comparison. The NASDAQ and E-mini futures rows use the actual futures series, which end 28 March 2024.
