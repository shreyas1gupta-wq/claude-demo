# re-engine-sources — the evidence pack's raw dossiers

Cited source dossiers written 2026-09-11 for the India Real-Estate Prediction Engine handoff
(`research/register/handoff-prompt-india-realestate-engine.md`). Literature and source
inventory only — **zero run cells, no census impact** (CN-DOSSIER precedent).

Reading order: the synthesised pack is
`research/register/india-realestate-evidence-pack.md`. These files are its working papers —
denser, longer, and messier. `_AUDIT-*.md` are the adversarial fact-checks;
`_SYNTH-*.md` the cluster syntheses; `_CRITIC.md` what is still missing.

Tag discipline in every file: `[2-SOURCE]` two independent sources, `[1-SOURCE]` one,
`[RECALL — unverified]` from model memory and NOT confirmed by search. WebFetch was
egress-blocked, so every external claim rests on WebSearch snippets.
