## 4. SEVERITY NOTE — the single most dangerous error

**B6 §1.1's manufactured cross-check (R2), and the fabricated country list it launders (R1).**

Not because a country list matters most — it does not — but because of **how** it is wrong. B6
did not simply mis-recall KSS's sample; it **built an argument that the mis-recall had been
checked**, using the pack's genuinely-verified vault data as the checking instrument:
*"JST's 18-country superset includes exactly four countries whose `hpnom` starts too late … which
raises confidence the remaining 14 are KSS's actual sample."* That sentence is engineered to
survive exactly the review this pack relies on. It cites a real primary file, performs visible
arithmetic (18 − 4 = 14), lands in the one dossier carrying the pack's only `[VAULT-VERIFIED]`
tag, and concludes with the words a synthesis agent is scanning for. And it is **internally
self-refuting**: it discards Finland (1905) and Switzerland (1901) as "too late" for an 1870-2012
panel while keeping Italy (**1970**) and Spain (**1971**) — sixty years later — in the list it is
purporting to validate. The vault data it cites contradicts the conclusion it draws from it.

That is a worse failure than a hallucinated author-year-journal triple, because a bare triple gets
tagged `[RECALL]` and chased. **This one arrives pre-laundered.** The tag discipline in `_HEAD.md`
§0 — the thing standing between this pack and a permanently embarrassing citation — is defeated
not by a claim that evades the tags but by a claim that *appears to have already cleared them*.
Any auditor who checked only whether the JST numbers were real (they are — C1/C2) and not whether
they supported the inference would have passed it.

**Three consequences for synthesis.** (i) Strike the sentence; do not re-tag it. An invalid
argument does not become a weak argument at `[1-SOURCE]`. (ii) Take KSS's sample from
`partB-cases.md:25-27` (desk-`[Verified]`, and note its own 15-names-for-14 defect) rather than
from B6, and resolve the Italy slot against the AER paper itself. (iii) Treat every "partial
cross-check", "raises confidence", and "independently attested" construction in this pack as a
**refuted pattern until re-derived** — R14 is the same failure mode in a different costume, where
four dossiers convert a gateway-level CONNECT refusal, which never reached DNS and would return
