# Appendix C — Pre-Registration Hypothesis Register

Companion to `docs/MASTER_PLAN.md` (§16 index) and `docs/DESIGN.md`. Binding template per DESIGN
§11 item 6 (Contract §9): **hypothesis + mechanism, sample, metric, minimum economic effect sourced
from the cost stack, test procedure, stop rule.** A hypothesis is not live research until it exists
as `research/register/preregistrations/H##.md` (this row expanded, PR-merged, reviewer = the other
team member) **before its test code runs** (MASTER_PLAN §10). This file is the master index; every
row below must spawn that file at the stated Phase, not before, not with parameters retuned after
a first look. Rejected = permanent — a new mechanism argument is a new H## with its own count.

**Mechanism categories** (Contract §5): **(i)** behavioural/structural persistent under crowding ·
**(ii)** capacity limit · **(iii)** genuine risk premium · **(iv)** institutional constraint ·
**(cal)** calibration/validation exercise carrying no alpha-decay claim of its own (feeds a
mechanical formula, a risk-ceiling check, or a cost/capacity number) · **reduce-only** = Tier-C,
may only cut exposure, never add (Contract §4).

**Test-procedure shorthand**: CV = purged K-fold cross-validation (4–6 folds on ~380-obs monthly
India series, per DESIGN §11.8, not a textbook 10) · embargo = f(τ½) with **2× τ½ for Tier B/C, 1×
for Tier A** (§11.8) · Stambaugh = Stambaugh (1999) bias correction, mandatory on any persistent
predictor (§11.3) · OOS-vs-mean = out-of-sample R² judged against the expanding-window
historical-mean benchmark, never in-sample (Goyal-Welch convention, §11.5) · bootstrap = stationary
block bootstrap (Politis-Romano), block length ≈2–4×τ½, for every drawdown/tail claim (§11.7) ·
DSR = deflated Sharpe (Bailey–López de Prado) against the **cumulative program-wide trial ledger**
(`research/register/trial-ledger.md`), required before any Tier promotion (t>3 AND DSR>0, §11.6).

**Minimum economic effect** is always stated against the cost stack it must clear (`config/costs.yaml`):
cash delivery 24–32bps RT · index futures 8–16bps RT · turnover cost curve 0.35–0.70% NAV/yr at
100% liquid turnover, 3.5–6.5% at 500% throttled · incremental fast-sleeve hurdle 3.0–6.0pp/yr gross
alpha vs the 100%-turnover book (D05 §4h) — never zero, and never "backtests well" alone (Contract §5).

**Priority flags**: ★★★ = named explicitly in the design/task brief as a top-value test · ★★ = high
(gates a book-defining decision or a live safety check) · ★ = medium · (plain) = low/monitor.
